# 数据结构简介

## 概念介绍
- **数据结构**：一种用于组织和管理数据的方法。
- **思维模型**：将现实世界的问题抽象为计算机可处理的形式。

## 主要类型
- 顺序存储结构（如数组）
- 链式存储结构（如链表）

## 存储与运算
- **顺序存储**：元素按顺序存放，便于访问。
- **链式存储**：元素通过指针链接，便于插入和删除。

## 时间复杂度与空间复杂度
- **时间复杂度**：衡量算法执行效率。
- **空间复杂度**：衡量算法所需资源消耗。

## 线性表
### 基本概念
- **逻辑关系**：元素之间的关联。
- **存储结构**：元素的物理位置。
- **运算效率**：插入、删除等操作的性能。

### 考点
- 逻辑关系
- 存储结构
- 运算效率

## 栈与队列
### 定义
- **栈**：先进后出（Last In, First Out）。
- **队列**：先进先出（First In, First Out）。

### 特点
- **栈**：顶部插入，底部删除。
- **队列**：两端均可插入/删除。

### 应用场景
- 插入和删除操作频繁时使用栈。
- 入队和出队操作频繁时使用队列。

## 数组与集合
### 数组
- **定义**：固定大小的存储结构。
- **优点**：随机访问高效。
- **缺点**：动态扩展困难。

### 集合
- **定义**：无序且不重复的元素集合。
- **常用操作**：添加、删除、查找。

### 性能考虑
- **查找**：平均 O(1)，最坏 O(n)。
- **插入**：平均 O(1)，最坏 O(n)。
- **删除**：平均 O(1)，最坏 O(n)。
